### 💡 Core Principles

- **🔒 Local-First & Privacy-First:** Software shouldn't spy on you. If an AI model or tool can run locally without external telemetry, it should.
- **🐧 Close to the Kernel:** Comfortable working with `/dev/input`, `udev`, BlueZ GATT, D-Bus, and Linux desktop ecosystems (Wayland & X11).
- **🛡️ Defensive & Security Minded:** From Wazuh SIEM automation and radio steganography to ensuring hardware keys (like YubiKey) stay isolated.
